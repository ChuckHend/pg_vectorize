# Security Policy

## Supported Versions

| Version  | Supported          |
| -------- | ------------------ |
| >= 0.27 | :white_check_mark: |
| < 0.27  | :x:                |

## Reporting a Vulnerability

Please use GitHub's built-in [private vulnerability reporting](https://github.com/chuckhend/pg_vectorize/security/advisories/new) to report any security issues you find.
 Please do not open public issues for security vulnerabilities.
 Thank you for helping keep the project secure!
